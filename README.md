# Meu Primeiro Projeto

## 📚 Sobre o projeto

Este projeto é um site criado para pessoas que, assim como eu,
amam ler, mas muitas vezes não têm com quem compartilhar informações,
opiniões e experiências sobre os livros que gostam.

O objetivo do site não é disponibilizar livros para leitura, mas
ajudar os usuários a descobrir novos livros, encontrar recomendações
e compartilhar opiniões sobre suas leituras.

## 🎯 Objetivo

A ideia é criar um espaço onde os usuários possam explorar livros
de diferentes categorias e encontrar informações que possam ajudá-los
a escolher o que ler.

Em cada livro, o usuário poderá encontrar:

- 📖 Nome do livro
- 📝 Sinopse
- ⭐ Avaliação em estrelas
- 💬 Comentários
- ❤️ Opção de favoritar
- 💭 Minha opinião como desenvolvedora
- 💬 Opiniões e comentários de outros usuários

Dessa forma, o site busca criar uma comunidade para pessoas que gostam
de ler e querem descobrir novos livros e conversar sobre eles.
